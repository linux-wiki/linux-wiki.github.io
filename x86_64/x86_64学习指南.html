x86_64 架构学习指南

基础概念

寄存器组

  • 通用寄存器：RAX, RBX, RCX, RDX, RSI, RDI, RBP, RSP, R8–R15
  • 段寄存器：CS, DS, SS, ES, FS, GS
  • 控制寄存器：CR0–CR4（控制 CPU 工作模式、分页等）
  • MSR（Model-Specific Register）：通过 RDMSR/WRMSR 访问的特有寄存器

寻址模式

  • 立即数寻址：mov rax, 0x10
  • 寄存器寻址：mov rax, rbx
  • 直接寻址：mov rax, [0x600000]
  • 基址+变址+位移：mov rax, [rbx + rcx*8 + 0x10]

数据宽度

宽度助记符大小
ByteBYTE8 位
WordWORD16 位
DwordDWORD32 位
QwordQWORD64 位

调用约定

System V AMD64 ABI（Linux / macOS）

  • 函数参数依次使用：RDI, RSI, RDX, RCX, R8, R9
  • 超出 6 个参数通过栈传递（从右向左压栈）
  • 返回值：RAX（64 位）或 RAX:RDX（128 位）
  • 调用者保存寄存器：RAX, RCX, RDX, RSI, RDI, R8–R11
  • 被调用者保存寄存器：RBX, RBP, R12–R15
  • 栈必须 16 字节对齐（调用 CALL 前）

Microsoft x64 ABI（Windows）

  • 函数参数依次使用：RCX, RDX, R8, R9
  • 超出 4 个参数通过栈传递
  • 调用者必须在栈上为前 4 个参数预留 32 字节 “shadow space”
  • 返回值：RAX

内存模型

虚拟地址

  • x86_64 采用 48 位虚拟地址（高 16 位为符号扩展，即”规范地址”）
  • 用户空间：0x0000000000000000 – 0x00007FFFFFFFFFFF
  • 内核空间：0xFFFF800000000000 – 0xFFFFFFFFFFFFFFFF

四级页表

CR3 → PML4 (Page Map Level 4)
          → PDPT (Page Directory Pointer Table)
               → PD (Page Directory)
                    → PT (Page Table)
                         → 物理页 (4KB)
  • 支持 4KB、2MB（大页）、1GB（巨页）
  • 页表项包含权限位：Present, R/W, U/S, NX

缓存层次

  • L1 Cache：指令/数据分离，~32KB，~4 周期延迟
  • L2 Cache：统一缓存，~256KB，~12 周期延迟
  • L3 Cache：共享缓存，~数 MB–数十 MB，~40 周期延迟
  • TLB：地址翻译缓存，分指令 TLB 和数据 TLB

分段机制

  • 实模式：段寄存器 × 16 + 偏移（20 位地址线）
  • 保护模式：段寄存器作为选择子索引 GDT/LDT，段描述符含基址+界限+权限
  • 长模式：段基址强制为 0（除 FS/GS），主要依赖分页

指令集

常用通用指令

指令功能
MOV数据传送
ADD/SUB加减运算
CMP比较（设置 EFLAGS）
TEST按位与测试
JMP无条件跳转
Jcc条件跳转（JE, JNE, JG 等）
CALL函数调用（压栈返回地址）
RET函数返回（弹栈跳转）
PUSH压栈
POP弹栈
LEA加载有效地址（不访存）

SIMD 与浮点指令

  • SSE / SSE2 / SSE3 / SSE4：128 位 XMM 寄存器（XMM0–XMM15）
  • AVX / AVX2：256 位 YMM 寄存器
  • AVX-512：512 位 ZMM 寄存器
  • 标量浮点：ADDSD, MULSD 等操作 XMM 寄存器

特权指令

  • SYSCALL / SYSRET：快速系统调用/返回
  • IRETQ：中断返回（64 位）
  • LGDT / LIDT / LLDT：加载描述符表
  • LTR：加载任务寄存器
  • INVLPG：刷新 TLB 单条映射
  • MOV CRn：操作控制寄存器

中断与异常

IDT（Interrupt Descriptor Table）

  • 每个表项 16 字节（门描述符）
  • 类型：中断门（关中断）、陷阱门（不关中断）、任务门

常见中断向量

向量助记符说明
0DE除法错误
6UD未定义指令
13GP一般保护故障
14PF缺页故障

系统调用流程（Linux x86_64）

用户态：mov rax, __NR_xxx  ; 系统调用号
        syscall
内核态：entry_SYSCALL_64
        → do_syscall_64(regs, nr)
        → sys_call_table[nr](...)
        → sysretq

安全与保护

权限环

  • Ring 0：内核态，最高权限
  • Ring 3：用户态，最低权限
  • Ring 1/2 基本未使用

CPU 安全特性

  • SMEP（Supervisor Mode Execution Prevention）：Ring 0 禁止执行用户态页
  • SMAP（Supervisor Mode Access Prevention）：Ring 0 禁止访问用户态页（除非显式允许）
  • NX / XD 位：页表项中的不可执行位，标记数据页不可执行
  • KPTI（Kernel Page-Table Isolation）：Meltdown 漏洞的软件缓解方案

内存保护

  • ASLR（地址空间布局随机化）：随机化栈、堆、mmap、代码段基址
  • Stack Canary：栈帧中的随机值，检测栈溢出
